# 계산 규칙

관련 문서: [requirements.md](./requirements.md), [content-model.md](./content-model.md), [technical-plan.md](./technical-plan.md)

## 1. 기본 원칙

- 초기 버전은 양력 생년월일만 사용한다.
- 계산은 모두 클라이언트에서 처리한다.
- 표기용 숫자와 내부 저장용 숫자를 구분한다.
  - 내부 canonical 번호: `0~21`
  - 표시 label: `0/22`, `1`, `2` ... `21`

## 2. 탄생카드 계산 규칙

### 2.1 계산식

1. `YYYY + MM + DD`를 계산한다.
2. 나온 합의 각 자리 숫자를 더한다.
3. 결과가 한 자리 숫자(`1~9`)가 될 때까지 반복한다.
4. 최종 한 자리 숫자가 탄생카드다.

### 2.2 성격

- 탄생카드는 사용자의 가장 기본적인 중심 성향을 뜻한다.
- 초기 정책상 탄생카드는 한 자리 숫자만 사용한다.

## 3. 페르소나 카드 계산 규칙

### 3.1 정의

- 자리수 축약 과정에서 처음 등장한 `10~22` 숫자를 페르소나 카드로 본다.
- `10~22`가 한 번도 등장하지 않으면 페르소나 카드는 없다.

### 3.2 우선순위

- 두 자리 숫자가 여러 번 등장할 수 있으면 첫 번째 숫자를 사용한다.
- `22`는 내부적으로 `0`으로 매핑하되, UI에서는 `0/22 바보`로 표기한다.

### 3.3 페르소나 카드가 없는 경우

- UI는 섹션을 제거하지 않는다.
- 대신 "이번 계산에서는 별도 페르소나 카드가 나오지 않았어요. 바깥으로 드러나는 모습도 탄생카드의 결을 크게 공유합니다." 같은 단일 카드 안내 상태를 사용한다.

## 4. 날개 카드 규칙

### 4.1 정의

- 날개 카드는 본 서비스의 고유 해석 개념이다.
- 표준 타로 용어가 아니며, "내 카드처럼 살지 못할 때 기울어지는 방향"을 뜻한다.

### 4.2 계산식

- `날개 카드 = 탄생카드 - 1`

### 4.3 순환 처리

- 탄생카드가 `1`이면 날개 카드는 `0/22 바보`로 본다.
- 따라서 날개 카드는 내부적으로 `0~8` 범위를 가진다.

## 5. 연도 카드 규칙

### 5.1 계산식

1. `MM + DD + 대상 연도`를 계산한다.
2. 각 자리 숫자를 더한다.
3. 결과가 `22` 이하가 될 때까지 반복한다.
4. 최종 값이 `22`이면 canonical 번호 `0`으로 매핑한다.

### 5.2 출력 범위

- 결과 화면에는 `작년 / 올해 / 내년` 3개를 함께 보여준다.
- 연도 카드 설명은 카드 자체 설명과 분리된 흐름형 문장을 사용한다.

## 6. 숫자 축약 표기 방식

UI 또는 디버깅용 로그에서 계산 과정을 아래 형식으로 기록한다.

```text
1997 + 10 + 17 = 2024 -> 2 + 0 + 2 + 4 = 8
2000 + 12 + 27 = 2039 -> 2 + 0 + 3 + 9 = 14 -> 1 + 4 = 5
```

표기 원칙:

- `+` 기호와 `=` 기호를 그대로 사용한다.
- 자리수 축약 단계는 `->` 로 연결한다.
- `22`가 나오면 `22 (0/22 바보)`처럼 병기할 수 있다.

## 7. 0 / 22 처리 정책

- 카드 데이터의 canonical 번호는 `0`을 바보 카드로 사용한다.
- 해석 문서에서는 필요 시 `0/22 바보`로 병기한다.
- UI 카드 번호 표시는 다음 원칙을 따른다.
  - 탄생카드: `1~9`
  - 페르소나 카드: `10~21`, `0/22`
  - 날개 카드: `0/22`, `1~8`
  - 연도 카드: `0/22`, `1~21`

## 8. 계산 예시

### 예시 1. 탄생카드만 있는 경우

- 입력: `1997.10.17`
- 계산: `1997 + 10 + 17 = 2024 -> 2 + 0 + 2 + 4 = 8`
- 결과:
  - 탄생카드: `8 힘`
  - 페르소나 카드: 없음
  - 날개 카드: `7 전차`

### 예시 2. 페르소나 카드 14가 나오는 경우

- 입력: `2000.12.27`
- 계산: `2000 + 12 + 27 = 2039 -> 2 + 0 + 3 + 9 = 14 -> 1 + 4 = 5`
- 결과:
  - 탄생카드: `5 교황`
  - 페르소나 카드: `14 절제`
  - 날개 카드: `4 황제`

### 예시 3. 페르소나 카드 10이 나오는 경우

- 입력: `2004.02.29`
- 계산: `2004 + 2 + 29 = 2035 -> 2 + 0 + 3 + 5 = 10 -> 1 + 0 = 1`
- 결과:
  - 탄생카드: `1 마법사`
  - 페르소나 카드: `10 운명의 수레바퀴`
  - 날개 카드: `0/22 바보`

### 예시 4. 페르소나 카드 11이 나오는 경우

- 입력: `1993.12.31`
- 계산: `1993 + 12 + 31 = 2036 -> 2 + 0 + 3 + 6 = 11 -> 1 + 1 = 2`
- 결과:
  - 탄생카드: `2 여사제`
  - 페르소나 카드: `11 정의`
  - 날개 카드: `1 마법사`

### 예시 5. 페르소나 카드가 22인 경우

- 입력: `1900.08.31`
- 계산: `1900 + 8 + 31 = 1939 -> 1 + 9 + 3 + 9 = 22 -> 2 + 2 = 4`
- 결과:
  - 탄생카드: `4 황제`
  - 페르소나 카드: `0/22 바보`
  - 날개 카드: `3 여황제`

### 예시 6. 연도 카드 계산

- 기준 생일: `10.17`
- `2025년`: `10 + 17 + 2025 = 2052 -> 2 + 0 + 5 + 2 = 9`
- `2026년`: `10 + 17 + 2026 = 2053 -> 2 + 0 + 5 + 3 = 10`
- `2027년`: `10 + 17 + 2027 = 2054 -> 2 + 0 + 5 + 4 = 11`
