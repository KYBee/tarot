# 구현 체크리스트

관련 문서: [technical-plan.md](./technical-plan.md), [calculation-rules.md](./calculation-rules.md), [ui-ux-spec.md](./ui-ux-spec.md)

## Must

- [x] 카드 콘텐츠 V2 필드와 원문 반영
- [x] 통합형·분리형 관계 패널
- [x] `내 중심` / `보이는 나` 단계 표시
- [x] 강점·그림자·관계·일·성장 상세 아코디언
- [ ] 320px / 360px / 430px 최종 모바일 QA

- [ ] 생년월일 입력 파서와 날짜 유효성 검사를 구현한다.
- [ ] 탄생카드 계산을 문서 기준으로 수정한다.
- [ ] 페르소나 카드 계산과 탄생·페르소나 통합형 UI를 구현한다.
- [ ] 작년 / 올해 / 내년 연도 카드 계산과 별도 흐름 문구를 연결한다.
- [ ] 결과 카드에 카드 타입 설명, 기본 의미, 그림 속 상징, 상징 해석, 역할별 프로필 설명을 모두 반영한다.
- [ ] 현재 `index.html / script.js / style.css` 구조를 유지한다.
- [ ] 카카오 공유 버튼을 결과 화면에 유지하고 fallback 상태를 정의한다.
- [ ] 모바일 360px 기준에서 레이아웃이 깨지지 않도록 조정한다.

## Should

- [ ] 카드 콘텐츠 데이터를 `script.js` 밖으로 분리한다.
- [ ] 앱 카피와 카드 콘텐츠를 별도 관리한다.
- [ ] 로딩 화면의 고정 2초 지연을 제거하거나 줄인다.
- [ ] 스와이프 카드 도트와 접근성 속성을 정리한다.
- [ ] 긴 설명 텍스트에 맞춰 카드 높이와 간격 체계를 조정한다.
- [ ] 공유 버튼에 앱키 미설정 / SDK 실패 fallback을 넣는다.

## Nice-to-have

- [ ] 카드 계산 trace를 결과 하단 또는 디버그용으로 노출한다.
- [ ] Web Share API fallback을 추가한다.
- [ ] 카드별 대표 이미지 또는 썸네일 정책을 추가한다.
- [ ] `prefers-reduced-motion` 대응을 넣는다.
- [ ] 결과 URL 생성과 공유 링크 고정을 위한 준비 코드를 넣는다.
- [ ] 음력 확장 가능성을 고려한 입력 구조를 미리 정리한다.
