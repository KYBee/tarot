## 2. 화면별 섹션 설명

### 2.1 랜딩 화면

- 서비스명
- 짧은 서브카피
- 생년월일 입력 필드
- CTA 버튼

UX 원칙:

- 첫 화면의 목적은 설명보다 입력 유도다.
- placeholder는 예시 포맷을 제시하되, 레이블을 대체하지 않는다.
- 입력은 `연 / 월 / 일` 3칸으로 분리하고, 월·일은 한 자리 입력도 허용해야 한다.

### 2.2 로딩 화면

- 짧은 전환 연출용으로 유지
- 권장 노출 시간: 300ms~700ms
- 계산이 즉시 끝나면 로딩 없이 바로 전환해도 무방

### 2.3 결과 스와이프 카드

카드 순서:

1. 탄생카드
2. 페르소나 카드

각 카드 내부 정보 순서:

1. 섹션 타이틀
2. 카드 타입 설명
3. 카드 비주얼 영역
4. 기본 의미
5. 그림 속 상징
6. 왜 이렇게 읽을까요?
7. 역할별 프로필 설명

### 2.4 연도별 흐름

- 상단 제목
- 작년 / 올해 / 내년 3열 또는 3단
- 각 연도 카드 이름과 3~4문장 해석
- 현재 연도 카드는 시각적으로 더 강조

### 2.5 하단 액션

- 1차 액션: 카카오 공유
- 2차 액션: 다시 하기

## 3. 모바일 / 데스크톱 반응형 기준

### 모바일

- 기준 폭: `360px ~ 430px`
- 스와이프 카드 한 장이 한 화면에 꽉 차되 좌우 패딩은 유지
- 연도별 흐름은 카드 높이보다 텍스트 가독성을 우선

### 태블릿 / 데스크톱

- 앱 최대 폭: `560px ~ 720px`
- 배경은 넓게 유지하되 본문 폭은 제한
- 스와이프 카드 경험은 유지하고, 과도한 좌우 여백만 줄인다

## 4. 카드 비주얼 가이드

- 현재는 카드 이미지가 모두 준비되지 않았으므로 텍스트 중심 카드 프레임을 기본으로 한다.
- 카드 번호, 카드명, 희미한 별/광원 효과만으로도 카드성을 유지한다.
- 추후 카드 이미지를 추가하더라도 텍스트 정보가 주인공이어야 한다.

## 5. 버튼 가이드

### CTA 버튼

- 골드 계열 그라디언트
- 터치 영역 48px 이상
- 눌림 상태와 포커스 상태를 구분

### 카카오 공유 버튼

- 카카오 브랜드 컬러 사용 가능
- 단, 전체 서비스 톤과 충돌하지 않도록 그림자/모서리/폰트 무드를 통일
- 키 미설정 시 비활성/대체 동작 필요

### 다시 하기 버튼

- 보조 액션으로 낮은 시각적 강조
- 현재 입력값 초기화와 랜딩 이동을 함께 처리

## 6. 타이포 가이드

- 제목: 감성적이면서 또렷한 디스플레이용 서체
- 본문: 한글 가독성이 좋은 산세리프
- 카드명은 섹션 제목보다 약간 더 상징적으로 보이게 처리
- 긴 설명은 행간을 넉넉하게 유지

## 7. 간격 가이드

- 섹션 간 간격: 24~40px
- 카드 내부 요소 간 간격: 8 / 12 / 16 / 24px 기준 스케일
- 하단 CTA는 스크롤 마지막에 안정감 있게 고정된 덩어리처럼 보여야 함

## 8. 색상 가이드

- 배경: 딥 퍼플 계열
- 강조: 골드
- 본문: 밝은 아이보리 계열
- 보조 텍스트: 채도 낮은 라일락/그레이 계열

권장 방향:

- 평평한 단색보다 안개 같은 그라디언트와 발광 효과를 조합
- 너무 진한 보라+흰색 대비만 반복하지 않도록 금속성 골드 포인트를 적절히 분배

## 9. 카카오 공유 버튼 위치와 상태

- 결과 화면 최하단에 배치
- 연도별 흐름을 다 읽은 뒤 행동하도록 구조 유지

상태 정의:

- `ready`: Kakao SDK 준비 완료, 정상 공유
- `fallback`: SDK 미설정, 링크 복사 또는 Web Share API
- `disabled`: 필수 설정 미완료, 안내 메시지 노출

## 10. 로딩 화면 필요 여부

- 필요는 하지만 필수는 아니다.
- 계산이 즉시 끝나는 구조이므로 긴 로딩은 UX 저하 요소다.
- 초기 버전은 짧은 전환 애니메이션으로 유지하되, 고정 2초 딜레이는 제거한다.

## 11. 스와이프 / 페이지네이션 동작 정의

- 기본은 가로 스와이프
- 도트는 현재 카드 위치와 연동
- 별도 페르소나 카드가 없더라도 두 번째 카드 장수는 유지한다.
  - 탄생카드와 같은 이미지, 번호, 이름을 사용한다.
  - 상태: `탄생·페르소나 통합형`

추가 동작:

- 키보드 포커스 이동 시에도 다음 카드 내용이 읽혀야 한다.
- 도트를 탭하면 해당 카드로 이동하는 기능은 선택 사항이나 권장된다.

## 12. 마이크로카피 가이드

- 입력 화면: "생년월일로 보는 나의 타로 프로필"
- 로딩: "카드를 해석하는 중..."
- 통합형 상태: "탄생·페르소나 통합형"
- 통합형 안내: "중간 축약 과정에서 별도의 두 자리 카드가 나오지 않아 탄생카드와 같은 카드로 읽습니다."
