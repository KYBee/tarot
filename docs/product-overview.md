# 서비스 개요

관련 문서: [README.md](./README.md), [requirements.md](./requirements.md), [ui-ux-spec.md](./ui-ux-spec.md)

## 서비스명

너의 타로는?

## 한 줄 정의

생년월일을 입력하면 계산 결과를 보여주는 계산기가 아니라, 사용자의 기질과 흐름을 읽어주는 모바일 우선 타로 프로필 웹 서비스.

## 문제 정의

- 기존 타로 계산형 웹페이지는 숫자 결과만 빠르게 보여주고, 프로필형 몰입감이 약한 경우가 많다.
- 사용자는 "내 카드가 무엇인지"보다 "그 카드가 나를 어떻게 설명하는지"를 읽고 싶어 한다.
- 모바일 사용 환경에서 한 번에 긴 설명을 다 보여주면 피로도가 높고, 공유까지 이어지기 어렵다.
- 타로 해석 서비스가 점집 톤으로 흐르면 부담스럽고, 반대로 너무 사전식이면 감성적 만족이 떨어진다.

## 사용자 경험 목표

- 입력 직후 "계산됐다"가 아니라 "내 프로필을 펼쳐본다"는 감각을 준다.
- 탄생카드와 페르소나 카드를 `내 중심 → 사회에서 드러나는 모습`의 흐름으로 읽게 만든다.
- 연도별 흐름은 예언보다 배움과 방향 제안으로 받아들여지게 한다.
- 결과 화면은 모바일에서 한 손 스크롤과 가로 스와이프만으로 편하게 읽힌다.
- 읽은 뒤 바로 카카오 공유로 이어질 만큼 결과 문구와 카드 제목이 명확해야 한다.

## 핵심 가치

- 프로필형 해석: 결과를 정답처럼 제시하지 않고 사용자의 성향과 흐름으로 읽어준다.
- 스토리텔링 UI: 카드별 정보를 한 번에 쏟지 않고 단계적으로 보여준다.
- 세련된 신비감: 우주적 무드와 골드 포인트를 쓰되 점집 이미지로 가지 않는다.
- 확장 가능성: 초기 버전은 정적 웹 구조를 유지하되, 추후 음력/결과 URL/저장 기능으로 확장할 수 있어야 한다.

## 타깃 사용자

- 자신의 성향을 가볍게 읽어보고 공유하고 싶은 10대 후반~30대 모바일 사용자
- MBTI, 심리 테스트, 운세형 콘텐츠를 소비하지만 너무 과장된 예언형 문구는 부담스러운 사용자
- 카카오톡을 중심으로 결과를 공유하는 한국어 사용자

## 톤앤매너

- 키워드: 신비로움, 우주감, 딥 퍼플, 골드 포인트, 세련됨, 감성적 몰입
- 피해야 할 방향: 점집/사주집 톤, 과도한 공포 연출, 저주/예언/단정형 문장
- 문장 인상: 부드럽고 설명적이며, "당신은 무조건 이렇다"보다 "이런 결이 잘 드러난다"에 가깝게 쓴다.
- 시각 인상: 어두운 배경 위 금빛 강조, 얇은 선, 유리 질감, 카드 프레임, 부드러운 발광 효과

## 핵심 화면 요약

### 1. 랜딩 화면

- 서비스명과 짧은 소개 문구 노출
- 연 / 월 / 일 분리 입력 필드와 CTA 버튼 제공
- 입력 부담이 적고 모바일 키패드 사용성이 좋아야 함

### 2. 로딩 화면

- "해석 중"이라는 짧은 감정적 전환 장치
- 계산 자체는 가볍기 때문에 대기 연출은 짧고 부드럽게 유지

### 3. 결과 스와이프 카드

- 탄생카드
- 페르소나 카드

두 장을 독립 정보가 아니라 "내 중심과 사회적 얼굴"을 잇는 프로필로 구성한다. 별도 페르소나 숫자가 없으면 탄생카드와 같은 카드를 쓰는 `탄생·페르소나 통합형`으로 설명한다.

### 4. 연도별 흐름

- 작년 / 올해 / 내년 3개를 함께 보여준다.
- 운세가 아니라 배움의 흐름과 변화의 방향으로 읽힌다.

### 5. 공유/재시작 액션

- 카카오 공유 버튼
- 다시 하기 버튼

## 제품 원칙

- 현재 mock UI의 전체 구조는 유지한다.
- 텍스트 콘텐츠가 많은 서비스이므로 레이아웃보다 정보 위계가 더 중요하다.
- 탄생/페르소나 카드 설명과 연도 카드 해석은 반드시 분리한다.
- 초기 버전은 회원가입 없이 단일 입력과 결과 조회에 집중한다.
