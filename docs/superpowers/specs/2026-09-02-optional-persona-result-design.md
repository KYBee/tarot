# 선택적 페르소나 결과 UI 설계

## 1. 목적

계산 과정에서 별도 페르소나 카드가 나오지 않았을 때 탄생카드를 복제해 `통합형`으로 설명하지 않는다. 실제 계산 결과에 맞춰 페르소나가 있는 사용자에게만 두 번째 카드와 관계 UI를 제공한다.

## 2. 결과 모델

프로필은 다음 두 상태를 가진다.

### 페르소나 없음

```js
{
  birthCard,
  personaNumber: null,
  personaCard: null,
  hasPersona: false,
  years
}
```

### 페르소나 있음

```js
{
  birthCard,
  personaNumber,
  personaCard,
  hasPersona: true,
  years
}
```

`personaCard`는 실제 두 자리 페르소나 숫자가 계산됐을 때만 존재한다. 탄생카드를 페르소나카드로 재사용하지 않는다.

## 3. 사용자 경험

### 3.1 페르소나가 없는 결과

- 탄생카드 한 장만 렌더링한다.
- 페르소나 슬라이드를 숨긴다.
- `내 중심 / 보이는 나` 단계 내비게이션을 숨긴다.
- 옆으로 넘기라는 스와이프 안내를 숨긴다.
- `페르소나 없음`, `통합형`, `같은 카드`라는 안내를 노출하지 않는다.
- 탄생카드 다음에는 `나의 프로필 더 보기`, 연도별 흐름, 공유/다시 하기가 이어진다.

사용자는 빠진 기능이나 예외 상태를 마주하지 않고, 자신의 실제 결과인 탄생카드에 집중한다.

### 3.2 페르소나가 있는 결과

- 탄생카드와 페르소나카드 두 장을 렌더링한다.
- `내 중심 / 보이는 나` 단계 내비게이션을 표시한다.
- 스와이프 안내를 표시한다.
- 두 번째 카드 상단에 탄생카드와 페르소나카드의 연결을 설명한다.
- 관계 배지는 `내 중심이 다른 모습으로 표현돼요`를 사용한다.

## 4. DOM과 렌더링

현재 2장 DOM 구조는 유지한다. 결과를 렌더링할 때 다음 요소의 표시 상태만 전환한다.

- `#item-persona`
- `.profile-steps`
- `.swipe-hint`

페르소나가 없으면 위 요소에 공통 숨김 상태를 적용하고 스와이퍼를 첫 위치로 초기화한다. 페르소나가 있으면 숨김 상태를 제거한다.

`renderPersonaCardSection`은 `hasPersona`가 `false`면 즉시 종료한다. 관계 카피 생성 함수도 페르소나가 있는 프로필만 받으며, 통합형 분기를 갖지 않는다.

## 5. 단계 내비게이션

- 한 장 결과에서는 단계 버튼 전체를 숨긴다.
- 두 장 결과에서는 현재 동작을 유지한다.
- 숨겨진 페르소나 슬라이드로 키보드 포커스가 이동하지 않아야 한다.
- 새 결과를 렌더링할 때 스와이퍼 위치와 활성 단계는 항상 첫 카드로 초기화한다.

## 6. 콘텐츠와 공유

- 메이저 아르카나 22장의 `roleDescriptions.persona` 데이터는 유지한다.
- 페르소나가 없는 결과에서는 해당 데이터를 사용하지 않는다.
- `APP_COPY.personaIntegrated`와 통합형 전용 문구는 제거한다.
- 공유 문구는 탄생카드를 항상 포함하고, 페르소나는 `hasPersona`가 `true`일 때만 포함한다.
- 상세 프로필은 현재와 같이 탄생카드 데이터를 기준으로 제공한다.

## 7. 접근성과 반응형

- 숨긴 페르소나 슬라이드는 시각적으로만 감추지 않고 접근성 트리와 포커스 순서에서도 제외한다.
- 한 장 결과는 320px 이상에서 가로 스크롤이 없어야 한다.
- 두 장 결과는 320px, 360px, 430px에서 기존 스와이프 동작을 유지한다.
- 단계 내비게이션의 `aria-current`는 두 장 결과에서만 사용한다.

## 8. 테스트

### 자동화

- 페르소나가 없는 프로필은 `personaCard: null`, `hasPersona: false`다.
- 페르소나가 있는 프로필은 실제 페르소나카드와 `hasPersona: true`를 가진다.
- 관계 카피는 페르소나가 있는 프로필에서만 생성된다.
- 결과 가시성 함수는 한 장/두 장에 맞는 상태를 반환한다.
- 공유 문구는 실제 페르소나가 있을 때만 페르소나 정보를 포함한다.
- 통합형 카피와 스타일이 활성 코드에서 제거됐는지 검사한다.

### 브라우저 QA

- `1997 / 10 / 17`: 탄생카드 한 장, 단계/스와이프 안내/페르소나 슬라이드 없음
- `1993 / 12 / 31`: `2 여사제 → 11 정의` 두 장과 관계 패널 표시
- 두 결과 모두 상세 프로필, 연도 흐름, 다시 하기, 공유 fallback 유지
- 320px, 360px, 430px 가로 넘침 확인
