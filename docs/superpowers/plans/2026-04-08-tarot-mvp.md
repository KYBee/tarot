# Tarot MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 문서 기준 계산 규칙과 카드 콘텐츠를 반영한 `너의 타로는?` 정적 웹 MVP를 현재 구조 안에서 실제로 동작하게 만든다.

**Architecture:** `index.html / script.js / style.css` 구조는 유지하고, 카드 콘텐츠는 별도 데이터 파일로 분리한다. 계산 로직은 `script.js`에서 테스트 가능한 순수 함수로 구성하고, DOM 렌더링과 이벤트 바인딩은 브라우저 환경에서만 초기화한다.

**Tech Stack:** HTML, CSS, Vanilla JavaScript, Node built-in test runner
